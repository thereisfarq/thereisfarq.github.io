Media converter

Convert local media files in your browser with FFmpeg WebAssembly. No upload or paid API.

CONV / 01

Direct media file links can be imported if the host allows browser access (CORS). YouTube and other streaming-page links are not direct media files and cannot be fetched by this static site.

Quality note. Conversion cannot restore quality missing from the source. Encoding runs locally in your browser; large files may need more memory and processing time.

Stem separator

Separate a mix into vocals, drums, bass and accompaniment stems for independent downloads.

STEM / 02

A public page URL is not the same as a direct audio file. Link import also depends on the host allowing browser access (CORS).

Local stereo split, not AI separation. This free browser mode extracts center and side information from stereo audio. It is a useful phase-based approximation, not a true vocal/instrument separator; mono files and mixes with off-center vocals may not separate well. Files stay on your device.

NOTES / 03
Local file selection: selecting a file in this page does not upload it to a server. The interface can inspect supported browser media and prepare files locally.

Media conversionFFmpeg WebAssembly loads in your browser to convert supported local files into MP3, WAV, MP4 or WebM.

Video-platform linksPages on YouTube and other streaming services usually do not expose a downloadable media file directly to a browser. Use content you own or have permission to download and a lawful source-compatible tool.
03
Stereo splitThis browser app exports center and side channels locally. True AI vocal/drum/bass separation still requires a separate pretrained model runtime.
